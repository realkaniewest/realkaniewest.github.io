Этот файл — точка входа для агента (Codex/Claude), который продолжает работу
над сайтом. Прочитай его целиком перед изменениями. Сайт уже живой и рабочий,

## TL;DR задачи

Владелец хочет переписать сайт на **React + Vite + TypeScript + Tailwind +
shadcn/ui** и внедрить 4 конкретных компонента с 21st.dev (исходники лежат в
`docs/codex/`), сохранив всю существующую «душу» сайта (терминал, ASCII-кот,
секретный пёс, konami). Затем задеплоить обратно на GitHub Pages
(`realkaniewest.github.io`).

Делай поэтапно, коммить часто, после каждого этапа проверяй сборку
(`npm run build`) и визуал. Не ломай прод между этапами — переключение на новый
билд делается одним последним шагом.

### Что уже реализовано в `js/main.js` (ОБЯЗАТЕЛЬНО сохранить поведение)

1. **ASCII-кот в окне терминала (хиро).** Сидит, моргает, виляет хвостом,
   умывается (лижет лапу), потом встаёт и **анатомически ходит на 4 лапах** в
   профиль вправо до края терминала, там умывается и идёт обратно. Кадры —
   массивы строк, аниматор на `setTimeout`. Все кадры ровно 7 строк.
2. **Секретный пёс по клику на кота.** Клик запускает **глитч-морф** (символы
   перемешиваются с `#*+%`, перетекание ~1с) и кот превращается в пса с будкой
   и миской справа, виляющим хвостом и высунутым языком. Повторный клик — морф
   обратно в кота.
3. **Typewriter** `$ whoami` в хиро-терминале с печатью вывода построчно.
4. **Интерактивный терминал** (секция/окно с `#shell`): реальный ввод команд,
   виртуальная файловая система `FS`, prompt `realkaniewest@dev:~$`.
   Команды: `help, ls (-a), cd, pwd, cat, tree, echo, whoami, neofetch, clear,
   pet, woof, meow, sudo, contact, history, rm`. Tab-автодополнение, история
   стрелками. ФС содержит папки `projects/`, `cats/` (породы котов),
   `dogs/` (породы собак), скрытую `.secrets/` (konami-подсказка, pet.sh, todo).
5. **Konami-код** (↑↑↓↓←→←→BA) — пасхалка.
6. **reveal-анимации** секций через IntersectionObserver, уважение
   `prefers-reduced-motion`.

При переписывании на React **всё это должно остаться** и работать так же.
Кадры кота/пса и содержимое FS бери как источник правды из текущего
`js/main.js` — не выдумывай заново, перенеси один в один.

## Целевой стек и где взять компоненты

Vite + React + TS + Tailwind + shadcn/ui (`@/` алиас на `src/`,
`@/lib/utils` с `cn`, компоненты в `src/components/ui/`).

Исходники 4 компонентов лежат локально в **`docs/codex/`** (не надо тянуть из сети):

| Файл в docs/codex | Куда | Где на странице |
| --- | --- | --- |
| `container-scroll-animation.tsx` | `src/components/ui/` | 3D-скролл-карточка, внутри неё — БОЛЬШОЙ хиро-терминал с котом |
| `display-cards.tsx` | `src/components/ui/` | секция «Проекты» — стопка карточек (6 проектов) |
| `gooey-text-morphing.tsx` | `src/components/ui/` | блок «обо мне» — морфинг слов |
| `theme-toggle.tsx` | `src/components/ui/` | переключатель темы в шапке |

Зависимости: `framer-motion`, `lucide-react` (+ shadcn-базовое: `clsx`,
`tailwind-merge`).

### Как именно использовать каждый

- **ContainerScroll** — обернуть им ХИРО: при скролле большой терминал с котом
  «ложится/встаёт» в 3D. Внутрь карточки положить React-компонент терминала
  (с тем же котом и typewriter). Кот должен остаться кликабельным (морф в пса).
- **DisplayCards** — заменить текущую сетку проектов. 6 карточек = 6 проектов
  realkaniewest. Иконку `Sparkles` можно заменить на тематические lucide-иконки
  (Terminal, Bot, Database…). Сохрани зелёную акцентную палитру, не синюю из демо.
- **GooeyText** — блок «обо мне». Слова для морфинга придумай в духе
  «бэкенд / парсеры / автоматизация / интеграции» + завершающая фраза-призыв
  вроде «сделаем твой проект лучше — вместе». Текст на русском, без эмодзи.
- **ThemeToggle** — в демо он только держит локальный `useState` и НИЧЕГО не
  переключает. Подключи НАСТОЯЩЕЕ переключение: класс `dark` на `<html>` +
  сохранение выбора в `localStorage`, плюс светлая палитра (сейчас сайт только
  тёмный — добавь light-токены). Можно через `next-themes`-аналог или вручную.
  Тема должна сохраняться между перезагрузками и уважать системную при первом входе.

## Деплой (GitHub Pages, user-site)

Репозиторий `realkaniewest/realkaniewest.github.io` — это **user site**, отдаётся
из корня. Сейчас Pages берёт готовые файлы из ветки `master`.

После перехода на Vite нужен билд:

- `vite.config.ts`: `base: '/'` (user-site, не project-site).
- Деплой через **GitHub Actions** (официальный `actions/deploy-pages` или
  `peaceiris/actions-gh-pages`), артефакт — папка `dist/`. Создай workflow
  `.github/workflows/deploy.yml`, в настройках Pages переключи Source на
  «GitHub Actions». Не коммить `dist/` и `node_modules/` (уже в `.gitignore`).
- Проверка после деплоя: `curl -I https://realkaniewest.github.io` → 200,
  открыть и убедиться, что кот ходит, клик морфит в пса, терминал принимает
  команды, тема переключается.

## Жёсткие правила (безопасность и качество)

- **Никакого innerHTML с пользовательским вводом** в терминале. Сейчас вывод
  идёт через `textContent` / `createTextNode` — сохрани это в React: команды
  рендерь как текст, НЕ через `dangerouslySetInnerHTML`. Никаких `eval`,
  `new Function`, динамического `import()` из ввода. Терминал — это витрина без
  реального бэкенда, он ничего не исполняет.
- Никаких внешних запросов с пользовательскими данными, никаких трекеров,
  никаких сторонних скриптов кроме шрифтов и npm-зависимостей сборки.
- Не коммить секреты. В этом репозитории секретов быть не должно вообще.
- Доступность: сохранить `prefers-reduced-motion` (кот статичен, без морфа и
  typewriter), фокус-стили, контраст в обеих темах, alt/aria где нужно.
- Производительность: сайт должен оставаться лёгким и быстрым.
- Тексты для людей — на русском, от первого лица, без длинных тире (—) и эмодзи.
