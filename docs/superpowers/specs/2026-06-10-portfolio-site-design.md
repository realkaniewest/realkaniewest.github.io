# Сайт-портфолио Егора — Design

Дата: 2026-06-10
Статус: одобрен Егором

## Цель

Одностраничный сайт-портфолио на русском в духе ghostty.org (тёмный терминальный
стиль, ASCII-анимация), но не клон и не «нейрослоп». Цель: клиент посмотрел и
написал в Telegram. Хостинг: GitHub Pages, репозиторий `realkaniewest.github.io`.

## Решения

| Вопрос | Решение |
| --- | --- |
| Хостинг | GitHub Pages, репо realkaniewest.github.io (user site, корень) |
| Стек | Чистая статика: index.html + css/style.css + js/main.js, без сборки и библиотек |
| Язык | Русский |
| CTA | «Написать в Telegram» → https://t.me/realkaniewest2; почта isokokluu@gmail.com |
| Акцент | Терминальный зелёный #7ee787 на тёмном #0d1117/#0e1018, не синий Ghostty |
| Шрифты | JetBrains Mono (код/терминал) + Inter (текст), Google Fonts |

## Визуальный язык

- Фон почти чёрный с синим подтоном, едва заметная точечная сетка (radial-gradient dots, как у Ghostty).
- Вся «графика» — ASCII и окна терминала с macOS-кружками. Никаких стоковых иконок, градиентных блобов, глянца.
- Карточки проектов оформлены как мини-терминалы с заголовком `~/projects/<slug>`.
- Жирные крупные заголовки (Inter 700+), monospace для команд, путей, чипов.

## Поведение

- Анимация котика стартует сразу, typewriter в хиро — сразу после кадра котика.
- Секции появляются мягким fade-up через IntersectionObserver (один раз).
- Анимации уважают prefers-reduced-motion (котик статичный кадр, без typewriter).
- Адаптив: < 900px терминал под текстом хиро, карточки в одну колонку, метрики 2x2.
- Никаких внешних JS-зависимостей; шрифты — единственный внешний ресурс.

## Деплой

Репо `realkaniewest/realkaniewest.github.io`, ветка master, GitHub Pages из корня.
Создание репо и пуш через gh CLI (уже залогинен). Проверка: открыть
https://realkaniewest.github.io после первого деплоя (1-3 минуты на сборку Pages).

## Критерии приёмки

1. Сайт открывается на realkaniewest.github.io, грузится < 1 сек.
2. Котик анимированно лижет лапку в окне терминала, курсор мигает, whoami печатается.
3. Все 7 секций на месте, данные реальные (цифры с Kwork, 6 проектов).
4. Кнопки ведут на t.me/realkaniewest2 и mailto:isokokluu@gmail.com.
5. На мобильном (375px) ничего не ломается, терминал читаем.
6. Дизайн узнаваемо «терминальный», без типового ИИ-глянца; не выглядит клоном ghostty.
7. prefers-reduced-motion отключает анимации.
